Exlo

A Figma plugin that lets designers export multiple frames at once — any format, any size, straight to a ZIP. One click beats fifty.

Challenge

Exporting from Figma was a 20-step ritual

Every designer who's shipped a brand kit knows the pain: select frame, open export panel, choose format, repeat sixteen times. Figma's native export is frame-by-frame by default. Batch workflows exist, but they're buried and fragile.

The problem wasn't lack of features — it was the number of decisions the designer had to hold in their head simultaneously: which frames, which formats, which scales, where the files go.

Discovery

What designers actually do

Talking to designers revealed a consistent pattern: most had built private workarounds — scripts, export presets, naming conventions — just to get a clean ZIP out of Figma without losing track of what was exported.

The core insight: the bottleneck isn't the export itself. It's the selection and confirmation step. Designers want to see exactly what they're about to export before they commit.

Design

Plugin panel as decision surface

The design reduces the interaction to three moments: select frames on the canvas, pick formats in the panel, hit export. The panel mirrors the Figma selection state in real time — you see exactly which frames are queued.

Format toggles are persistent across sessions. Once you've set SVG + PDF + PNG 2×, it stays that way until you change it. No re-picking every time.

Plugin UI — annotated screenshot
Prototype

Live in Figma Community

The plugin is built with Figma's plugin API — TypeScript frontend, bundled UI with inline assets so it loads instantly. JSZip handles the archive; all files are named and packed client-side, no server call required.

The main engineering challenge was getting the ZIP to work reliably inside the Figma sandbox. Solution: inline JSZip into the compiled UI bundle so it ships as part of the plugin, with no external network dependency.

Lessons

What I'd do differently

Shipping a Figma plugin to the Community platform has a review process with strict validation. The first rejection came from an undeclared networkAccess field in the manifest — a two-line fix that took 48 hours of review turnaround to discover.

The broader lesson: read the Figma review checklist before writing a single line of plugin code. The submission rules are non-obvious and underdocumented. I now keep a pre-submission checklist that runs through every manifest field.
